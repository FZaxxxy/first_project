# 机械臂智能体控制代码（STM32 / HAL 库）

> 基于 STM32 主控的六自由度机械臂智能体项目。
> 通过两块 PCA9685 多路 PWM 驱动板级联，驱动六台大扭矩高功率舵机，
> 实现多自由度协调运动（抓取 / 放置 / 旋转等固定动作），并引入
> 目标识别 + 反向运动学（IK）+ 路径规划的智能自主抓取闭环控制。

## 二、依赖与工程集成方式

1. 本项目为 **STM32 HAL 库** 工程代码，不包含 CubeMX 生成的外设初始化文件。
2. 请在 STM32CubeMX 中新建工程并配置：
   - I2C1（速率 100kHz，连接两片 PCA9685）
   - USART1（115200-8-N-1，用于串口指令与日志）
   - TIM2（1ms 周期，作为运动控制节拍）
   - 若干 GPIO（按键输入 / 光电传感器输入 / 夹爪限位）
   - 将本目录源码加入工程即可。
3. 头文件搜索路径需包含：`Core/Inc`、`Drivers/BSP/*`、`Motion`、`Algorithm`、`App`。

## 三、两个工作模式

| 模式   | 触发方式             | 说明                                             |
| ------ | -------------------- | ------------------------------------------------ |
| 手动   | 按键 / 串口指令       | 执行预编程固定动作序列（HOME/PICK/ROTATE/PLACE…） |
| 智能   | 串口 `AUTO` 指令      | 视觉识别目标 -> 坐标转换 -> IK 解算 -> 自主抓取    |

## 四、串口指令一览

```
HELP             显示指令帮助
HOME             回到初始位姿
PICK             演示 抓取->旋转->放置 动作序列
ACTION <名称>    执行指定动作（见 action.h 动作表）
J <关节> <角度>  单关节绝对定位（如 J 2 45）
IK <x> <y> <z>   逆运动学解算并移动（单位 m，如 IK 0.30 0.05 0.20）
AUTO             进入智能自主抓取模式
MANUAL           返回手动模式
DBG <0/1/2/3>    设置日志级别
```

## 五、使用说明

- 所有硬件相关参数（舵机脉宽范围、关节限位、DH 参数、相机标定等）
  均集中在 `Core/Inc/config.h`，并标注"须自定义"，按实际硬件修改即可。
- 本项目按四个阶段交付，每阶段代码均可独立编译验证。
